# School Sports Tracker — clean Nuxt 4 rebuild

This is a new frontend codebase, not a copy of the previous application. Nuxt 4 app directory conventions, dedicated layouts, composables, feature components and Tailwind CSS.

The original application is archived on branch `archive/pre-v3-rebuild-2026-11-21`.

Supabase is external and is not modified by this codebase.

This initial implementation includes the public home, sign-in, school context and workspace overview. Additional routes and workflows are still being implemented. Do not mistake this for feature parity.
